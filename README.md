# WiFi controlled robot with camera.

The robot streams video from its camera to an API server. Users can control the robot and access the video stream via the website: .... 

### How to:
* **Robot Setup:** After turning on the robot, a WiFi network named "..." will become available. Connect to this network using any WiFi-enabled device. A flashing blue LED indicates that the access point is ready. Once connected, a configuration web page will automatically open. Enter your local WiFi network details (SSID and password) and click the "Submit" button. The robot will then attempt to connect to the specified network, indicated by the blue LED blinking slowly. When the blinking stops and the light stays solid, the robot has successfully connected and started broadcasting the video stream. Any potential connection errors will be signaled by a flashing red LED.
* **Control and Video Feed:** To connect to the robot, visit the website "...." and enter the static password: "ILN367". Use the following keys to control the robot: **WSAD** for driving, **Q** to rotate the camera left, and **E** to rotate the camera right.

### Instrukcja:
* **Obsługa robota:** Po włączeniu robota dostępna powinna być sieć WiFi o nazwie "...", do której należy się podłączyć dowolnym urządzeniem sieciowym. Sygnalizuje to migająca niebieska dioda. Po podłączeniu otworzy się strona internetowa, na której należy podać dane twojej sieci WiFi (nazwa, hasło). Po wprowadzeniu danych i wciśnięciu przycisku "Submit" na stronie robot zacznie łączyć się ze wskazaną siecią, sygnalizując to powolnym miganiem niebieskiej diody. Kiedy miganie ustąpi, robot pomyślnie się połączył ze wskazaną siecią i rozpoczął transmisję obrazu. Wszelkie potencjalne błędy połączenia sygnalizowane są błyskiem czerwonej diody.
* **Sterowanie i odczyt obrazu robota:** Aby połączyć się z robotem należy wejść na stronę internetową "...." i wpisać stałe hasło - "ILN367". Aby sterować robotem używać następujących przycisków: **WSAD** - jedź, **Q** - obrót kamery w lewo, **E** - obrót kamery w prawo.
